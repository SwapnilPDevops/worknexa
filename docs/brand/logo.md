# Worknexa logo

The product name is Worknexa. The tagline is “Your Work. One Intelligent Place.”

Final logo files belong in `frontend/public/brand/`:

| File | Use |
|---|---|
| `worknexa-mark.svg` | App icon, favicon, and sidebar mark |
| `worknexa-wordmark.svg` | Optional horizontal wordmark, when a drawn wordmark exists |

`frontend/public/brand/worknexa-mark.svg` is a temporary hub mark so the interface has a recognizable icon. Replace that file with the final artwork. Keep the same path so the shell and favicon do not need new references.

`frontend/public/assets/logo.svg` is the earlier project-board icon. It is not the Worknexa logo.
